# Декоративная гравюра

`archaeological-engraving.png` — оригинальный результат генерации встроенным Image Gen. `archaeological-engraving.webp` — версия без потерь для сайта. Гравюра встроена в HTML и используется только как декоративное обрамление, отдельно от изображений в вопросах.

Промпт: оригинальная музейная гравюра одним кобальтовым цветом `#3035ad` на чистом белом фоне; каменный бифас, греческая амфора, ионическая капитель, скифский олень, втульчатый топор, папоротник, оливковые ветви и акант по четырём углам. Широкая пустая белая середина для интерфейса. Точная перекрёстная штриховка, без текста, логотипов, водяных знаков, зерна, градиентов и элементов интерфейса.

Цель — поддержать выбранную пользователем стилистику иллюстрированного атласа, не воспроизводя логотипы и конкретные иллюстрации референса.
