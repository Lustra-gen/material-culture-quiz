# История материальной культуры — викторина

Учебная викторина с 52 вопросами, 19 вопросами с иллюстрациями и редактором вопросов. Набор включает авторские правки и добавления преподавателя.

**Открыть сайт:** https://lustra-gen.github.io/material-culture-quiz/

## Игра

Откройте сайт или файл `index.html` в браузере. Вопросы перемешиваются, ведущий показывает ответ и выставляет от −1 до +2 баллов. Прогресс игры сохраняется в браузере.

## Редактор вопросов

Внизу страницы нажмите **«Редактор вопросов»** или **«Править этот вопрос»**. Можно менять тему, вопрос, ответ, источник и иллюстрацию, добавлять и удалять вопросы, задавать от двух до шести вариантов ответа. Поддерживаются изображения PNG, JPEG, WebP и GIF до 1 МБ.

Кнопка **«Сохранить вопрос»** сохраняет изменения в текущем браузере и начинает новую игру. Изменения в редакторе доступны только в этом браузере; они не обновляют сайт для остальных посетителей.

Чтобы перенести викторину вместе с изменениями, нажмите **«Скачать HTML с вопросами»**. Скачанный файл работает самостоятельно и содержит вопросы и картинки.

Чтобы обновить вопросы на опубликованном сайте для всех посетителей, замените `index.html` в репозитории скачанным HTML-файлом, сохранив имя `index.html`, и сделайте коммит. Пользователи, которые уже сохраняли собственный набор в браузере, продолжат использовать свою локальную версию.

## Публикация

GitHub Pages публикует корневую папку ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Сборка, сервер и установка зависимостей не требуются: весь сайт находится в `index.html`.

Подписи источников иллюстраций сохранены в соответствующих вопросах.

## Оформление

Белый фон, кобальтовая типографика и оригинальная гравюра с археологическими предметами по краям. Декоративная гравюра не служит иллюстрацией или научным источником к вопросам. Изображения находок в самих вопросах сохранены без цветовых фильтров.

Шрифты и гравюра встроены в `index.html`, поэтому скачанная HTML-копия сохраняет оформление без подключения к интернету. Исходные файлы декора и шрифтов находятся в `assets/`.
